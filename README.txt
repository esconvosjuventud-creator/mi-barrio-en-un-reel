MI BARRIO EN UN REEL — SITIO PARA GITHUB PAGES

SUBIDA CORRECTA:
1. Descomprimir este ZIP.
2. Subir TODO el contenido a la raíz del repositorio de GitHub.
3. Mantener la carpeta assets con las cuatro imágenes dentro.
4. En Settings > Pages seleccionar main y /(root).
5. Esperar el despliegue y actualizar con Ctrl+F5.
